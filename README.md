# Saravanan P — Developer Portfolio

Welcome to the official personal portfolio website of **Saravanan P**, B.Tech Information Technology student at VSB Engineering College.

## 🚀 Built With
- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, CSS3 Glassmorphism
- **Animations & 3D**: Framer Motion, GSAP, Three.js (@react-three/fiber & @react-three/drei)
- **Icons**: Lucide React

## 🛠️ Features & Sections
- **Hero Section**: 3D interactive graphics, custom cursor, sound effects, and dynamic CTA buttons.
- **About Me**: Academic background, core values, and engineering philosophy.
- **Skills Matrix**: Categorized breakdown covering Languages (Python, Java, HTML5/CSS3), Core Concepts (DSA, OOP, DBMS/SQL), Tools (MySQL, VS Code, Postman, Linux), and Soft Skills with interactive live code snippets.
- **Interactive Projects**: Showcase of featured AI & Web Development projects with interactive modal details.
- **Resume Modal**: Instant viewable/downloadable PDF and Word resume document preview.
- **Contact Section**: Social links, email, phone, and direct contact interface.

## 💻 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/saravanan-9629/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
